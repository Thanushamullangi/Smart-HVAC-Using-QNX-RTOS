# Python analysis

Copy the tested `data_analysis.py` from your working project into this folder.

Expected dataset location in the repository:
`Datasets/Occupancy_Estimation.csv`

Install dependencies from the repository root:

```bash
python -m pip install -r requirements.txt
```

Run:

```bash
python python/data_analysis.py
```

Add the generated graph/output only if it is useful and permitted to publish. Do not commit private or restricted datasets.
